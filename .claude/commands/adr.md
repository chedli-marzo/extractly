Draft a new Architecture Decision Record for: $ARGUMENTS

1. Read `docs/decisions/README.md` and the highest-numbered existing ADR to get
   the next number and the house style.
2. Read `docs/decisions/0000-template.md` for the format.
3. Read whatever code or docs the decision touches — do not write an ADR from
   assumption.
4. Draft the file as `docs/decisions/NNNN-kebab-title.md` with status
   `Proposed`, using the Decision / Context / Consequences format. The
   Consequences section must have real Negative entries; an ADR with no
   downsides has not been thought through.
5. Add the row to the table in `docs/decisions/README.md`.
6. Report what you wrote and what is still undecided. Do not mark it `Accepted`
   — that is the user's call.
